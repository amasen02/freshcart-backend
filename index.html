What it is

A .NET 10 microservices reference e-commerce platform with twelve bounded contexts, deliberately different architectural styles, shared building blocks, integration events, transactional outbox messaging, and local .NET Aspire orchestration.

Who it is for

Portfolio reference repository for contributors and maintainers working with twelve bounded contexts, architecture patterns, backend services, infrastructure, deployment, and documentation.

Capabilities

Twelve bounded contexts

Identity, Catalog, Pricing, Basket, Ordering, Inventory, Payment, Delivery, Notification, CustomerSupport, Reviews, and Reporting use distinct architectural styles and persistence choices.

YARP API Gateway

The edge gateway provides the browser trust boundary, reverse proxy routing, and cookie-to-JWT BFF exchange for downstream services.

Reporting suite

Reporting provides executive KPI dashboards, QuestPDF invoices, ClosedXML Excel exports, scheduled Azure Blob reports, and event projections into MySQL.

Transactional Outbox

Basket and Ordering use a transactional outbox with background publishing, while consumers use inbox-based idempotency for cross-service events.

Local orchestration host

The Aspire AppHost boots backing services, every microservice, and the gateway in one developer command for local development.

OpenTelemetry

Shared service defaults configure OpenTelemetry traces, metrics, and logs, plus service discovery, HttpClient resilience, and default health-check endpoints.

Process

  1. Database per service
  2. Cookie-first for browsers, JWT for everything else
  3. Integration events
  4. Polyglot persistence
  5. Hexagonal (Ports & Adapters)
